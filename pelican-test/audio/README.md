# 原创程序配乐

`npm run audio` 在独立 Chromium 页面的 `OfflineAudioContext` 中合成整首配乐，写出 `exports/audio/pelican-score.wav`（137 秒、48 kHz、双声道、24-bit PCM）。无需启动美术画布、p5 或 WebGL。过程同时输出 `analysis.json`、`peaks.json`、`events.json`、`ffprobe.json` 和 `loudness.txt`。重新运行可重建，随机噪声与混响采用固定种子。

运行 `npm start` 后，可打开 `/audio.html` 单独合成、播放和下载；完整播放器直接解码导出的同一 WAV，并以音频时钟驱动画面。`renderScore()` 返回 `{buffer, report}`，也可把同一个 AudioBuffer 接入实时 AudioContext。

## 音乐与合成

`score.js` 保存 120 BPM 的同一条原创 D 小调十二音动机、二十段事件和同步效果。声部是现代程序合成的近似，不宣称历史乐器或历史音乐的准确复原。

`synth.js` 不读取任何音频文件。弦类与拨弦用衰减谐波及轻微非谐性；钟、锣、甘美兰与车铃用独立模态；管乐和无词吟唱用振荡器、谐波及气声；电钢琴、萨克斯和流行主音使用 FM；无品贝斯含短滑音；鼓和机械声用噪声与指数降频的振荡器。所有音符包含起音和收尾包络。

八位段只调度 square1、square2、triangle、noise 四个声部；97.5 秒金币替换 square1 的普通音符；该段不接混响。示波器故障 91–91.5 秒的 FM 强度按半周期正弦变化，失谐尖叫限制在 79–79.5 秒。

蒸汽波先在独立 OfflineAudioContext 中渲染高四半音、151.190526 BPM 的原创爵士片段：Dm9、Bbmaj9、Cmaj9 电钢琴、无品贝斯、FM 萨克斯与有门限的卷积房间鼓。主时间 107–113 秒以 2^(-4/12) 播放，经过 4 秒高湿混响、4 kHz 低通、0.5 Hz / ±4 cents detune 及轻噪声。106.82–107 秒在穿框过程中播放原创轻柔电钢琴前奏，并完成从1至r的0.18秒减速；原始缓冲的前奏长度严格采用速率积分0.18×(1+r)/2，真正爵士首拍渲染在该前缀之后，因此107秒正好到达首拍。第一支BufferSource从106.82秒连续播放至109秒，在107及107.5秒均不重新启动，避免减速积分或wow导致无意回读、重复起音。109–110 秒用四个独立源重复同一 0.25 秒单元，110 秒回到正常源时间并用单支连续源播放至113秒；最后0.25秒加速。2–3 ms淡入淡出只用于这些实际源边界。0.5Hz微小wow是连续的设计内速度波动，源位置没有半秒一次的重置。长混响的尾音在 113.6 秒前收束。

Outro 125–133 秒含二十时代的主音色与各副乐器，129–133 秒渐弱；133–136.5 秒明确静音。136.5 秒后只剩原创模态车铃与其短尾，文件严格在 137 秒结束。

最终混音对二十个时代各使用一个固定总线增益，包括蒸汽波总线。增益根据已保存24-bit参考母带的每段RMS校准到共同参考值，避免聊天段进入蒸汽波时突增音量；不使用段内自动增益、限幅或压缩，各乐句的起伏和音色保持原样。全片最后统一归一化到0.78采样峰值。最终保存母带要求二十段RMS最大/最小不超过2.2、真峰值不高于-1dBTP；这些均由实际输出重新测量。

## 验证范围

`node --test tests/audio.test.mjs tests/audio-render.test.mjs` 检查动机、声部、磁带分段、WAV 编码和已生成母带；`npm run audio` 进一步调用 ffprobe 验证实际 WAV 格式、ffmpeg ebur128 测量真峰值与响度，并在浏览器对 107 秒片段执行播放推进检查。样本扫描验证全部二十段非静音、无 NaN、无削波及最后车铃前的静音。`node tools/verify-audio.mjs` 独立读取已保存的 24-bit PCM，每个样本逐一检查并写出 `wav-verification.json`，包括文件 SHA256、每段 RMS、声道差异与完整 133–136.5 秒静音检查；导出命令也会自动执行此检查。

这些是渲染、媒体播放与信号检查；不能代替人耳对合成近似、音色喜好和整片节奏的主观验收。
