# The Reedwheel Variations / 芦轮变奏

原创三小节动机：D–A–C–A–F / G–E–F–D–A / C–E–G–F–D。音符在十二拍内以长短交替的切分组织；基础和声为 Dm、B♭、C，120 BPM，第5秒为小节第一拍。所有旋律、音色、噪声、混响脉冲、音效都在本项目程序内生成；没有录音乐器、语音、TTS、采样包或现成提示音。以下乐器名称描述合成近似，不声称民族乐器录音的真实性。

01手鼓与无语词 /o/→/a/ 共振峰吟唱；02多泛音衰减竖琴；03非整数泛音青铜编钟；04含起音噪声与轻饱和的琵琶；05稀疏柔和古琴及泛音；06带气噪、颤音的笛与锣鼓；07纯音陶笛与短木鼓；08带轻微失谐、共鸣弦的西塔及双膜近似塔布拉；09留白气息箫；10非谐和甘美兰；11短促拨弦三味线；12双振荡器弓弦；13快速振幅颤动弦乐与79秒走调滑音；14泛音钢琴及管风琴；15正弦示波器与50Hz电子管底声，91–92秒音高扭曲；16两条限带方波、三角低音、确定性噪声四音乐通道；17FM铃声/MIDI感编曲与原创消息声；18下述真实二次渲染磁带爵士；19原创拨弦流行节奏；20柔和FM钢琴与合成弦垫。

车链的短高频金属激励贯穿正常骑行；每次过框给极轻车铃。金币97秒、1UP98秒为原创二音阶跃；聊天103/104秒消息声；129/131/133秒为带机械低频瞬态的摄影闪光声。埃及13秒短暂空出旋律，14秒回接。Outro将全部20段代表音色以交错声部回收，125–133秒逐渐稀疏渐弱；136.5秒只留一次车铃，137秒前12ms平滑收尾。

蒸汽波是两个实际 OfflineAudioContext 渲染。第一遍是高4半音、名义151.190525987 BPM的原创 FM 电钢琴 Dm9/B♭maj7/Cmaj9、滑润FM贝斯、FM萨克斯动机及短门限房间鼓。为让段首/段尾速率变化仍落在影片拍点，事件源位置由速率曲线积分求出，中段八分音符间隔精确对应该速度。第二遍将真正的干声 AudioBuffer 以 r=0.7937005259840998 播放：入口240ms从原速滑下，出口400ms恢复；4kHz低通，4秒固定种子长混响，高湿声、轻高通磁带噪声，0.5Hz、±3cent detune摇晃。源偏移使用同一名义速率积分；低幅wow为不到约1ms的音乐摆动，不改变独立音画提示事件。109–110秒将半拍250ms素材回放四遍，接缝6ms淡入淡出；110秒跳回当前正常源位置，不累积延迟。单独输出干声与处理后WAV可检查真实变化。

同一完整137秒、48kHz双声道AudioBuffer同时作为实时播放器缓存和离线WAV来源。暂停销毁音源，拖动从绝对偏移新建音源；异步渲染期间的暂停通过世代编号取消旧播放。原始波形整体峰值归一至0.89，不做会抽吸的自动增益。导出由浏览器逐16384采样帧将PCM16分块交给Node保存，并记录峰值、RMS、逐秒能量、SHA256、实时seek/取消验证及完整事件表。

执行：`node tools/audio.mjs`，结果在 `out/final/score.wav`、`audio-manifest.json`、三个审听段与蒸汽波干/湿声。`node --test tests/audio.test.mjs`检查动机、拍点、速率积分、跳针恢复、四通道、PCM及实际输出。最终有声MP4混流和完整实际播放由主代理负责。
