Status: stage 1, 2026-10-27. The pinned film runtime and capture dependencies are now installed. This register distinguishes conceptual references from incorporated software; it is not a blanket license for third-party media. It does not set a license for this project's original work.

**Tunai-0511 / meme67-art-history** — [repository](https://github.com/Tunai-0511/meme67-art-history).

If a later change deliberately incorporates any source excerpt, record the exact source path and revision, explain the reuse and include the original copyright plus complete MIT notice with that material before committing. The current implementation plan calls for independent source.

## Original media rules

All film visuals and audio are to be generated by original project code. Historical public-domain art provides technique/period context, with original staging and geometry. Fictional game, chat and short-video interfaces must use authored names/icons, with no real logos, characters, recognizable levels or sampled notification sounds. Record any new external component or asset before it enters the build.
