# 画幅间运动修正

参考：用户提供的 Superman in Flight，https://claude.ai/artifact/7F2XhpmgiuyxHKgQ9Vgr9Q 。实际观察8.45秒与9.5秒：相邻画幅横向排列，整排画幅向左移动，人物停留在画面中部并跨越边界，分别呈现相邻画幅的材质。只借鉴空间运动，不复制代码或画面。

根据用户随后提供的截图，展墙进一步改为820×820单位的方形画作，间隔54单位，顶部留白32单位。旧宽屏场景按高度等比缩放、居中截取方形窗口，不挤压自行车和人物。编号、中文名、英文名、年代统一放在画作下方，随画作一起横移；使用浅色展墙、细边与柔和投影。

镜头每6秒前进一幅的距离，鹈鹕锚点固定在画面水平中心。相邻画作同时可见，角色按全局位置重映射，在画幅边缘由剪裁切换材质；间隔内接续素描骑手与道路，不重置脚踏相位。原有场景内的特殊缩放、跳跃、定格与竖屏窗口保留。Intro和Outro保留原时长与音乐。

验证：20幕乱序重绘、63次边界检查；测试覆盖正方形尺寸、等比缩放、标题空间、画幅间距、相机速度、强拍边界和邻幅可见性。12秒示范片为out/travel-demo.mp4；修订版成片及接触表同步重新导出。
