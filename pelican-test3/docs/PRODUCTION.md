## 已确认规格
137 秒；1920×1080；120 BPM；0–5 秒序幕，20 幕各 6 秒，125–137 秒发布会。1 秒引子后强拍为 1+2k 秒。脚踏周期 1 秒。画框中心跨越时间为 5+6k 秒。所有画面为时间纯函数，定种子纹理可缓存；量化局部表演不量化镜头。

## 分工与接口
Canvas 由 p5.js 创建。场景在 1000×1000 设计空间作画，主调度等比扩展为 1777.78×1000 的宽屏视野，原点居左上，场景可以在宽屏范围内布置环境；不得拉伸主体。src/scenes/01.js 至 20.js 各导出 metadata 和 draw(ctx, localTime, env)。env 包含全局 t、宽高 W/H、rig(ctx,x,y,scale,t,style)、工具 kit。骑行道路默认 y=780，角色轮胎触点=780；主调度控制框与拍点。场景只写获分配文件，禁止修改共用模块。

## 验证命令与通过条件
`npm test`：区间、强拍、踩踏与末端边界；`npm run check`：浏览器加载、无错误、同时间乱序渲染哈希一致、控制条 seek。
`node tools/render.mjs --fps 60 --width 1920`：逐帧送 ffmpeg，137 秒 H.264；`npm run audio`：OfflineAudioContext 48kHz 双声道 WAV；`npm run sheet`：首尾及 20 幕、转场接触表。
最终以 ffprobe 确认 1920×1080、恒定帧率、137 秒及 AAC 音轨；检查 WAV 峰值和首尾，对拍事件来自同一时间轴。
