# 原创程序配乐

`audio/synth.js` 独立合成全部声音，不使用外部录音、音色库、MIDI 文件或歌曲片段。旋律为本项目原创12拍乐句，主调 D minor；全片120 BPM，1秒引子后强拍为1+2k秒，场景在5+6k秒切换。

## 接口
- `renderAudio()`：异步返回48kHz、双声道、137秒 AudioBuffer，内部使用 OfflineAudioContext；缓存一次，多个调用共享同一结果。
- `playFrom(t)`：优先解码本项目已导出的 `out/soundtrack.wav`，以 Web Audio 从 t 秒播放；没有有效成片配乐文件时回退到 `renderAudio()`。不把合成等待计入影片时间。
- `stop()`：停止并保留当前位置。
- `playhead()`：返回实际音频时钟对应的全片秒数。
- `cancelPlayback()`：同时取消尚未完成的异步起播。

交付预览直接播放导出的WAV混音样本，拖动后从目标偏移重启，不另行实时重排音符，因而包含正确的混响历史。WAV为16bit量化；程序合成入口保留浮点AudioBuffer，首次全长合成可能需要数分钟，已导出文件的预览无需再次等待。

## 音色设计
20幕分别采用合成声道共振吟唱/手鼓、谐波竖琴、非整数倍青铜钟、亮拨弦琵琶、低音古琴、含气笛子与锣鼓、陶笛与木鼓、FM拨弦与双音高鼓、箫、非谐金属甘美兰、短促三味线、双失谐弦乐、滑音尖叫弦乐、钢琴与三角波管风琴、正弦蜂鸣及低频嗡声、四声道芯片音、FM铃声及原创消息声、磁带商城音乐、短促流行节拍、柔钢琴与正弦合成器。它们是为叙事设计的程序音色近似，不能视为民族乐器的实录或历史音乐复原。

芯片段配置为两个方波、一个三角波和一个噪声声部；金币在97.5秒借用第一个方波声道播放原创双音，避免额外增加声道。呐喊、示波器错旋钮（91.5–92秒）、89秒通电、发布会快门（130、130.5、131.5、132.5秒）和末尾136.5秒车铃均有独立合成事件，并与画面事件对齐。结尾20类音色共同演奏后渐弱，135.6秒前收净齐奏，末尾仅车铃；最后20ms淡至零。

## 蒸汽波制作链
先以独立 OfflineAudioContext 渲染10秒原创商城素材，源速度 `120/0.7937≈151.1906 BPM`，音高升4半音；含FM电钢琴的大七/小九和弦、滑入音高的无品贝斯近似、FM萨克斯近似、短扩散回声形成的门限鼓。

然后在全片107–113秒将源缓冲以0.7937倍率重放，经约4kHz低通、4.2秒确定性噪声脉冲混响（高湿声）、0.5Hz/±5 cents detune摇晃和轻底噪。进入时0.28秒减速，离开前0.25秒加速；中段第2秒取同一0.25秒半拍循环四次，第3秒恢复对应源偏移。每段边缘作6–9ms淡入淡出抑制突变，混响连续。入口滑速为有意效果，可能带来入口素材短暂偏拍，后续跳针/恢复点仍严格固定于全片时钟。

## 电平
母线轻压缩，离线完成后统一归一化保留峰值余量。任何读取/合成异常会抛错，不静默交付空音轨。波形峰值、时长、样本一致性与实际音色审听由最终验收脚本检查。

## 2026-10-29 实测
已重新运行 `node tools/audio.mjs`，WAV 为137秒、48kHz、双声道，峰值约0.67684；20幕各自的RMS均高于0.001，未削波。`node audio/verify.mjs` 检查全部场景、铃前静音、尾部归零，并实际运行Web Audio的起播、暂停、seek及取消：本机已导出配乐起播约441ms，91.5秒seek后时钟正常推进，暂停后位置不变，取消后没有继续播放。报告为 `out/audio-verification.json`，包含WAV的SHA-256及修改时间。

这些是代码、PCM和浏览器播放时钟的验证；未作主观听感审听，不能据此声称民族乐器音色完全写实或混音已获人工听感确认。
